## LoadingPanel 英文铭牌贴片「文字超框」修复

**现象**：`_output/art_translate_loading/*/preview_en.png` 里英文大字被贴片边界齐刷刷切掉
顶部/左边；标签、台词也贴到贴片边缘。实测 05 的 BRUTUS 顶部缺 46px、左边缺 16px，
03 缺 26px，07 缺 41px。

**根因**：`loading_plate_overlay.py` 的贴片 bbox 是用 `name_box` / 红条几何推算的，
但大字是斜排 15° + 纵向拉伸的，旋转后左上角会跑到 name_box 的
左外侧 `h/2·sinθ` 和上外侧 `w·sinθ + h/2·cosθ`，几何框根本框不住；
`NAME_HEADROOM` 只参与算 bbox、**没有约束字本身**，所以字照样往外长。

**改法**（脚本已重构）：
- `layer_ink_quad()`：图层 alpha 外接框 → 绕锚点旋转 + 平移到落点，得真实墨迹四边形；
- `build_lines()`：只排字，返回 [(图层, 锚点, 角度, **底图坐标**落点)]（顺序很重要：
  先定落点再定画布，反过来会自咬）；
- `plate_box()`：贴片 bbox = 红条 ∪ 台词带 ∪ 擦除区 ∪ 墨迹，再外扩 `PLATE_PAD=6`；
- 大字加硬约束：旋转后墨迹不得越过「名字区上沿 = name_box 顶 - 92」，越过就降字号；
- bbox 对 `LANGS` 全部语言取并集、小字擦除框按最长译名推 —— 保住
  「一张图一组 anchor」不变量（LoadingPlateGeom.lua 不按语言分表）；
- `geom.json` 新增 `ink_clip_px`，`verify` 新增硬检查「文字未越出画板」；面积上限 15%→25%。

**结果**：九张全部 9/9 PASS，`ink_clip_px` 全 0，贴片面积 8.2%~13.8%（原 10%~15%）。

## 环境坑（重要）

- 本机 shell 的 `grep` 实际是 **ripgrep 的 shim**，`grep "a\|b"` 不会按「或」匹配，
  会静默返回空 —— 排查代码时差点误判成「文件被回滚」。**判内容一律用 python 直读**。
- 仓库 `.git/hooks/post-commit` 是 Qoder 的 tracker。这次 `git commit` 之后，
  改动被并进了另一个 agent 的提交（message 是 `docs(memory): 测试服部署全链路…`），
  内容没丢但 **commit message 与改动不符**。提交后要 `git show --stat HEAD` 核对。
