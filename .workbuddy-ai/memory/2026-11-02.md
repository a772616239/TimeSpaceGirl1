### 两个坑
1. 🔴 **沙箱代理会打死 Google API**：环境里 `HTTP(S)_PROXY=127.0.0.1:51736` 对
   `oauth2/androidpublisher.googleapis.com` 返回 `Tunnel connection failed: 502`，
   `googleapiclient` 表现为 `TimeoutError` / 进程被 SIGTERM（exit 137）。
   跑之前必须 `env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u all_proxy`，
   并且**用 `requests` 手撸 REST**，不要用 `googleapiclient`（它走 httplib2 仍会挂）。
2. Play Developer Reporting API 在 Cloud 项目 `804098807906` 里**未启用**（403 SERVICE_DISABLED）
   ⇒ 崩溃率/ANR 率暂时只能读 `stats/crashes` CSV，不能用 API 查。启用入口在 403 报文的 activationUrl。
