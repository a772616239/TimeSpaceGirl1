- `CountryFlagUtil.Apply` 用**弱键表**登记「画的是自己」的节点；`RefreshSelfFlags()` 就地重画，

## 大招小卡换分辨率跑到画面中部（13:2x 修，提交 `a49f42e86` / `34efe2799`）

**现象**：用户把 Game view 换成 1440x2960 后，`HelpHeroMiniCard_Mine` / `_Enemy`
（`BattleUltCard`）从左上/右上角滑到画面中部，被技能栏压住。

**根因**：卡片定位「跟随技能栏」= 直接复制 `myRect_Skill` 的 anchorMin/Max，
而技能栏锚在画布**垂直中心** `(0,0.5)`。`CanvasScalerAdapter` 在宽高比 < 16:9
时把 matchWidthOrHeight 切成 0（匹配宽度）⇒ 画布宽度恒 1080、高度随屏幕变
（1920 → 2220）。中心锚点的节点不会随画布变高而「留在原处」，而是整体下移，
所以卡片跟着滑到中部。**实测（Image1 归一化顶距）：1080x1920 = 47.9%，
1080x2220 = 55.7%**。

**改法**：定位只认屏幕顶角 —— anchor `(0,1)` 我方 / `(1,1)` 敌方，
`y = -(顶部血条带下沿 + 25 + 642.5*0.26)`，血条带下沿从 `UpRoot/EnemyHP`
实测（164.36，取不到退 165）；`x = ±140` 贴边。`GetSkillBar` 只留「跟随消失 +
压层级」两个用途，注释写明不能再用来定位。

**验证**：`.workbuddy/tools/probe_ult_card.py`（Unity 桥 + 假画布）实测
1080x1920 / 1080x2220 / 1440x2960 三档，卡片顶边距屏幕顶边恒 189~190px、
尺寸恒 280x330 ⇒ 不再随分辨率漂移。

🔴 **踩坑**：用 python 改这个 lua 会把 CRLF 洗成 LF，diff 直接变 334/330 行
（真实改动只有 37/33）。改完务必 `file` 看行尾，必要时
`bytes.replace(b'\r\n',b'\n').replace(b'\n',b'\r\n')` 回写后再重编字节码。
