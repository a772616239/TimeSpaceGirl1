## 00:30 宝典开箱特效 0.6 → 0.7（`0f117c6d7`）

- 用户反馈「UI_effect_GuaJi_Box_BaoDian 改成 0.7，改 transform 没有生效」。
  原因同 10-19 记录：`partical_click1..5` 是 `ScalingMode = Local`（忽略父级 transform），
  所以动容器 `UI_effect_GuaJi_Box_BaoDian` 的 scale 视觉上零变化；容器本身也不能缩
  （`FightPointMapOnHook.SetEffect` 拿它的 world position 当战利品线 `DOMove` 终点）。
- 做法：`bake_baodian_scale.py` 改造成支持「增量重烘焙」——新增 `FROM_SCALE`（当前已烘焙倍率 0.6）
  与 `SCALE`（目标 0.7），`FACTOR = SCALE/FROM_SCALE`，期望值由 `ORIG_* × FROM_SCALE` 推出，
  重复跑仍会被断言拦住。重跑前记得同步改 `FROM_SCALE`。
- 结果：click localScale `0.1508011 → 0.1759346`；Shape 粒子 startSize `1.8/0.6→2.1/0.7`、
  `0.3/0.06→0.35/0.07`、`0.06/0.12→0.07/0.14`、`0.9→1.05`；startSpeed `10.5/3.5、35/7、1.4/0.7`；
  限速 `0.7、0.35/0.07、0.21/0.07`。共 95 增 95 删，与 0.6 那次同构。
- 提交仍用「只暂存自己那份」：HEAD 版本跑同一脚本 → `git hash-object -w` +
  `git update-index --cacheinfo`，工作区里别人未提交的 UIShineSweep / Image / bg 节点改动原样留着。
- 🔴 未做视觉验证：Unity 编辑器没开（`.unity_bridge_port` 6400 不通），只做了数值回读。
- 待办：AssetBundle 需重打 `Prefabs/UI/Fight` 才会进包。
