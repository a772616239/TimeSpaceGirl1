# 英雄时光轴功能设计文档

## 功能概述

**功能名称**: 英雄时光轴 (HeroTimeline)
**功能目的**: 以"时空长河"为隐喻，将单个英雄的成长轨迹可视化 —— 等级跃迁、突破、装备更替、关键战役、羁绊解锁等重要节点按时间顺序铺陈在一条可交互的时间轴上。帮助玩家：
1. 回顾与单个英雄共度的旅程，增强情感投入；
2. 识别战力跃迁的关键节点，反推培养策略；
3. 与「英雄对比 (HeroCompare)」互补 —— 对比看横截面，时光轴看纵向演化。

**目标用户**: 中重度玩家、收藏型玩家、编队策略玩家
**入口位置**: 英雄详情页 (HeroDetailPanel) 右上角新增"时光轴"按钮（图标：沙漏 + 流光）

---

## 核心隐喻与设计方向

**主题词**: "星河长卷 · 一瞬永恒"

视觉隐喻：将英雄的成长看作在时空中留下的光轨。时间轴本身是一条发光的星轨，关键节点是轨道上的星辰。每个英雄根据其元素属性拥有不同的光轨色调（火 = 赤金、水 = 靛蓝、风 = 翠绿、光 = 白金、暗 = 紫黑）。

**Signature Element**: 当时间轴滚动到某个关键节点时，节点炸开成一颗星辰，伴随该英雄的标志性语音 + 对应战役/突破的粒子特效闪回（2 秒内）。

---

## 设计目标

| 目标 | 衡量方式 |
|------|---------|
| 情感价值 | 玩家打开率 > 40%（首周）；收藏型英雄平均查看次数 > 3 |
| 策略价值 | 节点跳转后能一键进入对应培养面板 |
| 性能目标 | 100 个节点滚动保持 60fps（中端机 Snapdragon 7 系列） |
| 信息密度 | 单屏展示 3-5 个节点，整轴支持缩放查看 |

## 节点类型

| 节点类型 | 图标 | 触发条件 | 信息内容 |
|---------|------|---------|---------|
| **初遇** (FirstMeet) | 🌱 | 首次获得英雄 | 获得途径、初始属性 |
| **等级跃迁** (LevelUp) | ▲ | 每 10 级一次 / 关键等级 (30/60/90) | 等级、属性增长 |
| **突破** (Breakthrough) | ★ | 每次星级突破 | 星级、消耗材料、战力变化 |
| **觉醒** (Awaken) | ✦ | 觉醒解锁 | 解锁技能、称号变化 |
| **装备** (Gear) | ⚔ | 关键装备获取/替换 | 装备名、属性差 |
| **战役** (Battle) | ⚔ | 该英雄 MVP 的关键战斗 | 战役名、伤害、结果、回放入口 |
| **羁绊** (Bond) | ♡ | 与其他英雄羁绊解锁 | 羁绊对象、加成 |
| **皮肤** (Skin) | 👗 | 皮肤获取/装备 | 皮肤立绘缩略图 |

**节点聚合规则**: 当两个节点时间间隔 < 24h 且同类型，折叠为一个聚合节点，展开后列出明细（避免早期刷级污染时间轴）。

## 交互设计

### 主时间轴操作

| 操作 | 行为 |
|------|------|
| 横向滑动 | 滚动时间轴，节点按惯性滚动并磁吸到最近节点 |
| 双指捏合 | 缩放时间轴（日/月/年视图切换） |
| 长按节点 | 弹出节点浮窗预览（不展开卡片） |
| 点击节点 | 展开节点详情卡片（从节点位置弹出） |
| 拖动年份刻度尺 | 快速跳转到指定年份 |

### 筛选

- **类型筛选**: 全部 / 等级 / 突破 / 装备 / 战役 / 羁绊（多选）
- **时间范围**: 近 7 天 / 30 天 / 今年 / 全部
- **搜索**: 按节点标题或战役名搜索

### 节点详情卡片操作

| 按钮 | 行为 |
|------|------|
| ▶ 回放战役 | 跳转到战报回放（如支持）或显示战斗摘要 |
| 跳转培养 | 回到英雄培养页，定位到对应模块 |
| 分享 | 生成节点卡片图（PNG），含英雄立绘 + 节点信息 + 游戏二维码 |

### 动效设计

| 时刻 | 动效 |
|------|------|
| 进入时光轴 | 星尘粒子从中心炸开 → 时间轴从中心向两侧生长（0.8s） |
| 节点首次点亮 | 节点炸开成星辰 + 英雄语音 + 粒子光环（1.5s） |
| 节点磁吸 | 轻微回弹 (easeOutBack) + 星光涟漪 |
| 卡片展开 | 从节点位置向上弹出，带弹簧阻尼 |
| 滚动 | 节点随滚动速度产生运动模糊（仅高端机） |
| 当前最新节点 | 持续流光拖尾 + 呼吸脉冲 |

## 数据结构

### 节点数据 (Lua Table)

```lua
local TimelineNode = {
    id          = "node_hero_1024_20240315_001",
    heroId      = 1024,
    type        = "Awaken",          -- FirstMeet|LevelUp|Breakthrough|Awaken|Gear|Battle|Bond|Skin
    timestamp   = 1710489120,        -- unix seconds
    title       = "觉醒 · 星尘使",
    subtitle    = "解锁主动技能「星河倒转」",
    snapshot    = {
        level       = 50,
        star        = 5,
        power       = 23100,
        powerDelta  = 4650,
        attrs       = { hp = 18500, atk = 1420, pdef = 680, mdef = 540, spd = 168 },
    },
    resources   = {
        { id = "item_stardust_tear", count = 5 },
        { id = "item_radiant_stone", count = 20 },
    },
    unlocks     = {
        { type = "skill", id = 102403, name = "星河倒转" },
        { type = "title", id = "title_stardust_envoy" },
    },
    battleRef   = nil,               -- 若为 Battle 节点，指向战报 id
    bondRef     = nil,               -- 若为 Bond 节点，指向羁绊英雄 id 列表
    skinRef     = nil,               -- 若为 Skin 节点，指向皮肤 id
    media       = {
        voiceLine = "vo_hero_1024_awaken",
        vfx       = "vfx_timeline_awaken_stardust",
    },
    isMilestone = true,              -- 关键里程碑，金色高亮
}
```

### 存储策略

- **热数据** (近 30 天节点): 内存 + 本地 SQLite 缓存
- **冷数据** (历史节点): 服务端按需拉取，分页大小 50 节点
- **数据生产**: 在现有事件总线 (`EventDispatcher`) 上监听 `HeroLevelUp`、`HeroBreakthrough`、`BattleEnd` 等事件，由 `TimelineRecorder` 模块异步写入

### 接口草案

```
GET  /api/hero/{heroId}/timeline?from=2024-01-01&to=2024-12-31&types=Awaken,Breakthrough&page=1&size=50
POST /api/hero/{heroId}/timeline/share   body: { nodeId }  -> 返回分享图 CDN URL
```

## 与现有功能的联动

| 现有功能 | 联动方式 |
|---------|---------|
| **英雄对比 (HeroCompare)** | 对比结果页新增"查看 TA 的时光轴"按钮 → 并排双轴对比模式 |
| **战报系统** | 战役节点一键跳转战报回放 |
| **英雄详情页** | 详情页头部显示"下一个里程碑"预告卡片，点击直接进入时光轴 |
| **羁绊系统** | 羁绊节点显示双方立绘缩略图，点击可跳转到对方时光轴 |

## 性能与降级

| 机型等级 | 策略 |
|---------|------|
| 高端 (Snapdragon 8 / A14+) | 完整粒子 + 运动模糊 + 语音 |
| 中端 (Snapdragon 7 / A12) | 简化粒子 + 关闭运动模糊 + 语音 |
| 低端 (Snapdragon 6 / A10 及以下) | 关闭粒子与语音，节点展开用简单淡入，时间轴改为列表模式 |

**降级开关**: 玩家可在设置中手动关闭"时光轴特效"。

**节点上限**: 单英雄最多显示 500 个节点，超出部分由聚合规则合并。

## 边界与风险

| 风险 | 缓解措施 |
|------|---------|
| 老玩家英雄节点过多导致首屏加载慢 | 分页加载 + 默认从最新节点开始，向历史按需加载 |
| 时间轴视觉过于密集 | 智能聚合 + 默认筛选"关键节点"，玩家可切换"全部" |
| 与英雄对比双轴模式 UI 冲突 | 双轴模式作为 HeroCompare 的独立子页面，不复用本面板 |
| 关键战役数据缺失（早期版本未记录） | 缺失节点显示为"历史迷雾"样式，提示"该战役记录已遗失" |
| 分享图滥用 | 单节点每日分享上限 5 次；图片加水印 |

## 验收标准

- [ ] 英雄详情页可进入时光轴，时间轴按时间顺序展示节点
- [ ] 支持横向滑动、缩放、类型筛选、年份跳转
- [ ] 节点点击弹出详情卡片，卡片内按钮可正常跳转
- [ ] 关键里程碑节点有金色高亮 + 语音 + 粒子特效
- [ ] 与英雄对比的联动入口可用
- [ ] 低端机降级到列表模式且无明显卡顿
- [ ] 分享图生成成功并可保存到相册
- [ ] 节点聚合规则正确触发（24h 内同类型）
- [ ] 节点上限 500，超出自动聚合
