+ 商店页/搜索页实抓（经本机 7890 代理）

---

## 0. 一句话

**11 月根本没有可判定的数据（批量报表只出到 10-31 / 11-01）**；能看到的那一段——改名上线那一刻起——
**商店页访问量腰斩（-42% ~ -58%，泊松 z≈-4.9），而转化率一点没掉（5.84% → 5.56%）**。
所以「数据更差」不是文案写坏了，是**没人再看到这个页面**。

## 3. 归因：曝光掉，不是转化掉

- CR 5.84% → 5.56%（样本 24/411 与 4/72，差异远在噪声内）⇒ **页面本身没变差**。
- 访问量 -42% ~ -58%，且 10-27 之后连续 4 天稳定在 6/8/8/8（方差远低于泊松），是**regime change 不是抖动**。
- 唯一在 10-27 前后发生的事就是**四语标题全换**（N：时空群英/超时空美少女/Neon Valkyries → 群星列阵/Starhost）。

机制上有两个候选，**当前数据分不开**（见第 5 节口径坑）：
1. 旧名里的 `美少女 / 少女 / 时空` 是这三个市场的高频查询族，换名后整族匹配丢失；
2. 标题重写后被 Play 的「相关推荐 / 猜你喜欢」权重重置，推荐位曝光掉了。

## 5. 口径坑（下次别再踩）

1. **维度全被聚合**：`store_performance` 的 country / traffic_source 两列在包量级这么小时，
   全部塌成 `Other`（隐私阈值）⇒ **看不到国家、看不到来源、看不到搜索词**。想分离「搜索 vs 推荐」
   只能靠 Console 的商店分析页，API 拿不到。
2. **报表滞后 5~6 天**：今天 11-06，`stats/installs` 只到 11-01，`stats/store_performance` 只到 10-30，
   `202611` 的 store_performance 文件尚未生成。**任何「本周变差」的判断都只有 Console 实时数能看。**
3. `edits.listings` 是**已提交内容**，不等于公开页。10-24 10:00 的快照就已经是 N，但公开页到 10-27 才换
   ⇒ 归因时点要用公开页/流量断点，不能拿快照时间当上线时间。

## 6. 建议（按性价比）

| 级别 | 动作 | 为什么 |
|---|---|---|
| P0 | **查繁中检索面**：Console → 商店发布 → 逐语种确认 zh-TW 是「已发布」；同时提 Play 开发者支持工单，附上「同词 zh_CN 第 1 / zh_TW 未出现」的复现步骤 | 这是唯一“修好就白拿流量”的确定性故障，与文案无关 |
| P1 | **标题要不要把高频词拿回来**（决策项，需用户拍板）：zh `群星列阵：放置挂机卡牌RPG`(14) 还有 16 码位，可加「美少女」→`群星列阵：放置挂机美少女卡牌RPG`(17)；ja 同理。en `Starhost: AFK Idle Card RPG`(27) 已满，加不了 | 现在只有品牌词能命中，品类词 0 命中（实测）；把旧名里真正带量的 token 放回标题是唯一低成本的召回手段。风险：`美少女` 属品类描述不是全量断言，合规可过，但要确认美术口径仍是二次元美少女 |
| P2 | **别再用文案改排名**：这个包没有安装信号，标题词进不了品类榜（`idle card rpg`/`放置`全灭）。要排名先有量 | 11-02 那轮加 AFK/挂机，实测没换来任何品类命中 |
| P2 | **量从外面灌**：这是唯一能同时修复「活跃 74」「排名无信号」「CR 5.8% 偏低」的动作 | ASO 内部改写的边际收益已经见底 |
