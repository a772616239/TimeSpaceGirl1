# ASO 第二轮：数字口径纠错 + 标题补品类词（变体 P）

日期：2026-11-02 ｜ 包：`com.Warera.timespace` ｜ 变体：P（基线 O）｜ 台账：`aso-20261102-1510-copy-p`

---

## 0. 一句话

上一轮改名（N）四语标题都生效了，但运营数据读不出提升；复查文案时发现**「90 位角色」这个数字在配置表里找不到依据**
（实际 84 位可收集 / 73 位有专属语音），顺手把 en / zh-CN / zh-TW 三语标题补上当地检索词。**ja 标题不动**（已验证第 1）。

---

## 1. 为什么动：90 这个数字是推出来的，不是数出来的

`HeroConfig.xlsx` 实测（2026-11-02）：

| 口径 | 数量 | 取法 |
|---|---|---|
| 角色总行数 | **112** | `Id` 列为数字的行（表头 + 3 行类型/说明/校对行已排除） |
| 图鉴可见（玩家数得到的） | **84** | `ShowHeroLocation=1` |
| 有专属语音 | **74**（其中 73 落在上面 84 位里） | `HeroSound` 非空 |
| 全 Live2D | 111 / 112 | `Live` 有独立 id |

N 的生成脚本注释写「110 行减 20 个克隆体 = 90」，但实测**表里没有任何同名行**（112 个名字全不重复），
这个 90 是估的。Play 对商店文案有虚假宣传条款，`90` 与 `全阵容由声优演绎` 这类**全量断言**都属于该风险，
必须改成可核对的 84 / 73。

## 2. 改了什么

### 标题（30 码位上限）

| locale | 旧（O） | 新（P） | 码位 | 依据 |
|---|---|---|---|---|
| en-US | `Starhost: Idle Card RPG` | `Starhost: AFK Idle Card RPG` | 27 | en 品牌词前 30 全无 ⇒ 补 AFK 这一放置类核心检索词 |
| ja-JP | `群星の陣：放置カードRPG` | **不动** | 13 | 品牌词第 1、品类词第 3，不重新洗索引 |
| zh-CN | `群星列阵：放置卡牌RPG` | `群星列阵：放置挂机卡牌RPG` | 14 | 品牌词已第 1，补「挂机」这一简中高意图词 |
| zh-TW | `群星列陣：放置卡牌RPG` | `群星列陣：放置掛機卡牌RPG` | 14 | 繁体原名搜不到，补「掛機」扩大非品牌命中面 |

### 短描述（80 码位上限）

- en：`Idle card RPG: 84 legends, 9 squares, 5 fighters. Misplace one, run ends.`（73）—— 品类词前置
- ja：`歴史・神話・小説の英雄84人が同じ名簿に。9マス5枠、配置で生死が決まる放置カードRPG。`（45）
- zh-CN / zh-TW：`84 位跨时代角色，历史神话小说混编。九格五席，站错一格就团灭。`（32）

### 长描述

只做定点纠错（`scripts/aso/_gen_variant_P.py`，每条替换命中次数强校验，命中≠1 直接失败）：

- `90 位 / ninety / 英雄90人` → `84`
- `全阵容由声优演绎 / フルボイス / fully voiced / all voiced` → `73 位有专属语音`
- 段落结构、关键词植入、人名名单段**全部沿用 O**，不重写

闸门：`aso_lint.py --variant P --baseline O` ⇒ 四语 **红 0 黄 0**，标题/短描述/长描述均在硬上限内。

## 5. 没做的事（以及为什么）

- **没再改 ja 标题**：它现在是四语里唯一被验证有效的，动它等于拿唯一的正面结果去赌。
- **没重写长描述**：O 刚上线 2 天，关键词覆盖已经做过；这一轮的目的是纠错，不是再洗一遍。
- **没做 A/B**：该包日均商店页访问 16 人，1000 访问门槛要 62 天，任何转化率对比都是噪声。
- **没补语种**：客户端只有中/英/日 三套 UI，加 L2 语种等于「店面有字、游戏里没字」。
