## 2. 关键词资产盘点（2026-11-06 实测，`aso_scorecard.py` 自动产出）

| 语言面 | 品牌词 | 品类词 |
|---|---|---|
| zh-CN / HK | `群星列阵` **第 1**、`群星` 第 4 | `放置`、`放置卡牌`、`二次元放置`、`美少女`、`少女` **全部未出现** |
| zh-TW / TW | 全部未出现（含旧名 `時空群英`） | 全部未出现 |
| ja-JP / JP | `群星の陣` **第 1** | `放置`、`放置カードRPG`、`美少女`、`美少女ゲーム` 全部未出现 |
| en-US / US | `Starhost` 未出现 | `idle card rpg`、`afk idle`、`anime idle rpg`、`gacha` 全部未出现 |

三条可直接用的结论：

1. **只有品牌词有排名，且只在自己语言的面上有。** 这说明 Play 的索引是**按语言面**的：
   日文标题只在 ja 面生效，繁中标题在繁中面……本该如此——但繁中面**连品牌词都搜不到**，属异常（见 §5）。
2. **品类词对我们是完全封死的**，跟标题里有没有这个词几乎无关（P 里已经有 `放置挂机卡牌RPG`，仍 0 命中）。
   原因是没有安装信号 ⇒ 别再把「补品类词」当成能提量的手段。
3. **P 那轮加的 AFK / 挂机 是无效投入**：加完 4 天，品类面命中依旧为 0。

### 2.1 竞争结构实测：哪个词才是「真 token」（2026-11-06，`aso_scorecard.py --tokens`）

Play 没有公开搜索量 API（老联想接口 `market.android.com/suggest/SuggRequest` 现已 404），
改用**结果结构**作代理指标：抓该词前 10 条的标题，看多少条**自己标题里就有这个词**——
含得越多，说明这个词是「开发者公认要卡位的 token」，也说明搜索真的按它匹配。

复跑：`python3 scripts/aso/aso_scorecard.py --tokens 少女 美少女 二次元 放置卡牌`

| 词 | zh-TW 前10含词 | zh-CN 前10含词 | 判读 |
|---|---|---|---|
| **少女** | **10/10** | **10/10** | 唯一强 token，两个语言面都满格（少女迷境 / 少女戰爭 / 少女前線 全在卡） |
| 放置 | 7/10 | 3/10 | 强 token（槍手貓咪：放置射擊RPG 等） |
| 二次元 | 3/10 | 2/10 | 弱；且**意图混杂**（zh-CN 第 1 条 `漫客棧-二次元超快看漫畫`、第 2 条涂色书，都不是游戏） |
| 美少女 | 2/10 | 2/10 | 单独弱，但**它是 `少女` 的超串** ⇒ 免费搭上最强 token |
| 卡牌RPG | 1/10 | 1/10 | 弱 |
| 放置卡牌 | 1/10 | **0/10** | 组合短语**不是 token** |
| 二次元放置 / 放置美少女 | **0/10** | **0/10** | 同上：Play 不认短语，只认词元 |

两条硬结论：

1. **`美少女` 优于 `二次元`，不是因为它自己的量，而是因为分词器会把 `美少女` 拆出 `少女`。**
   最直接的证据：搜 `美少女` 时第 2、3 条是 `少女戰爭` / `少女前線`——**这两个标题里没有「美少女」三个字**，
   只有「少女」⇒ 匹配走的是 `少女` 子串。而 `二次元` 没有任何强 token 可搭，
   还会把漫画/涂色书的意图拉进来——在「留存已是主要排序信号」的口径下，拉错人是有负作用的。
2. **拼长短语无意义。** `放置卡牌` 1/10、`二次元放置` 0/10 解释了为什么 P 标题里明明有这几个字、仍 0 命中：
   不是权重不够，是这个词压根不被当作一个查询单元。

**所以标题里真正值得占位的只有 `少女`（→ 用 `美少女` 顺带拿到）和 `放置`，其余是装饰。**
这也解释了 P（加了 `挂机`）为什么注定无效：它增加的是词元数量，不是词元强度。

## 4. 视觉 / 转化侧（本轮不动，下一步）

⚠ **修正一条之前的错误判断**：先前写「转化率 5.6% 对休闲品类偏低」是拿错了基准。
AppTweak 2025 口径：Play 全类目均值 16.15%，但 **Games–Strategy 是全类目最低的一档，仅 6.6%**。
我们 5.6% ≈ 该品类基准的 85%，**列表页本身没有明显坏**。缺的是进店人数，不是说服力。

即便如此，n=72 访问下**任何 A/B 都读不出数**（要 1000 访问＝62 天）。
所以视觉侧只能做「单变量顺序测试」：一次只换一件事，看 14 天窗口的 CR 比值，不看绝对值。

优先级建议：
1. **首图（第 1 张截图）**：现在 6 张都是 1920×1080 横版、竖版画布加糊边（用户已定稿口径），
   但首屏卖点条在最下方，Play 卡片裁切后首图只露上半 ⇒ 建议做一版「卖点条上移到上 1/3」的首图单测。
2. **图标**：搜索/榜单里唯一 1:1 辨识元素，与同类（二次元放置）区分度决定点击。
3. 不要动截图张数与顺序（10-23 刚定稿，动了就叠加变量）。

## 7. 决定（已定，不再走「你来选」）

### 7.1 标题用 `美少女`，否决 `二次元`，Q 保持原样

依据是 §2.1 的实测，不是语感：

| 判据 | `美少女` | `二次元` |
|---|---|---|
| 能否搭上强 token `少女`（10/10，两面满格） | **能**（子串；搜 `美少女` 时第 2、3 条是 `少女戰爭`/`少女前線`，标题里没有「美少女」） | 不能 |
| 自身 token 强度（前10含词） | 2/10 | 3/10（略高但无强 token 可搭） |
| 意图纯度 | 高（搜的人就是要这类游戏） | **低**（zh-CN 前两条是漫画 App `漫客棧`、涂色书） |
| 拉错人的代价 | 无 | 有（留存已是排序信号，错人拉低排名） |

`--alt-title` 的二次元版**不采用**，`_gen_variant_Q.py` 那个分支保留但标注「已否决，勿用」。

至于「男角不符」的顾虑——`美少女` 在这个品类是**风格标签**（`末日戰姬-日系美少女策略卡牌` 同款写法），
不是人物描述，合规与用户预期都不构成问题。已过 `aso_lint` 四语红 0 黄 0。

### 7.2 但现在**不上线**，理由是可算的

时间线（从 `data_aso/online/` 快照逐版核对出来的，不是回忆）：

```
10-24 09:41  改名提交   超时空美少女：放置卡牌RPG → 群星列阵：放置卡牌RPG
10-27        公开页生效（访问 17.9/天 → 7.5/天 的断点就在这天）
11-02 15:10  P 上线      群星列阵：放置挂机卡牌RPG（+挂机 / +AFK）
11-06 今天   ← P 才活了 4 天
```

行业口径（AppTweak / PlayAudit / Apptenium 2025–26 三家一致）：
**Play 重新索引要 7 天，rankings 完全稳定要 3–6 周；7 天内不要判读。**
按这个口径，P 的**可读起点是 11-09**，而报表又滞后 6~7 天 ⇒ **最早 11-12 才能第一次看到 P 的数**。

也就是说：今天推 Q，等于把 P 变成一个**永远无法判读的实验**，而 P 上面的改名实验
（10-27 那次，唯一真正动过我们数字的事件）也一起作废——因为之后再没有干净基线。

**等 6 天的代价可以精确算**：当前 7.5 访问/天 × 6 天 ≈ 45 次访问，按 CR 5.6% ≈ **2.5 个安装**。
用 2.5 个安装换回「唯一一次可归因的改版读数」，这个交换没有犹豫余地。
