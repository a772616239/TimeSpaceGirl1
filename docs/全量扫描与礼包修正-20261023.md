## 1. 扫描口径

沿用 R10：`抽等值 = 招募券(19/20/87/50007) + 钻石/220`，`抽/元 = 抽等值 / 售价`。
`220` = 单抽直耗钻；`2000` = 十连。不计金币、经验、材料、英雄——所以**带英雄的礼包会被低估**，
这一点在第 5 节单独处理。

货架口径：`有计费点 + OnSaleRule 未被 1#999#999 门控 + Price>0` = **502 个**。

## 4. 结论三：两张 ¥68 周卡差 4 倍，根因是活动轨道缺口

`70002` 和 `70003` **同价（¥68）、同名（34010059 豪华周卡）、同 BaseReward（`16#680`）**，

| 产品 | 抽/元 | 相对礼包带 |

R10 已经把基金从 1.399 压到 1.000、礼包从 0.249 抬到 0.288，落差从 5.6x 收到 3.5x。
再往下走必须二选一：

- **A 压基金**：98 元 98 抽 → 85 抽（0.87），落差 3.0x。已买玩家的剩余节点会少给，需补偿方案；

倾向 A：基金是一次性限量商品，动它不影响复购货架，且补偿面只在"买过但没领完"的玩家。

### 7.2 成长手册 9 行内容完全相同
