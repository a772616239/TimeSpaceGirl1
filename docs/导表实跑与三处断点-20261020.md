## 三、断点 2：txt 每行多一个 TAB（已修，待重跑验证）


## 六、顺带修掉：导表的 Unity 占用检查从来没生效

`scripts/resource_build.sh:46` 原文：

```bash
if [[ ! -f "$ROOT/Library/SourceAssetDB-lock" ]] && pgrep -f "Unity.*-projectPath $ROOT" >/dev/null 2>&1; then
```

两处错：

1. `pgrep -f` **区分大小写**，而 Unity Hub 拉起的 GUI 命令行是小写 `-projectpath` ⇒ 永不命中；
2. 前置条件 `[[ ! -f Library/SourceAssetDB-lock ]]` 写反了 —— 那个 lock 正是「编辑器持有本工程」的产物，
   文件存在时反而把检查整个跳过。

后果：GUI 开着照样往下跑，两个实例争同一个 `Library`，最坏写坏库。
已改为 `pgrep -fl` + `grep -iF -- "-projectpath $ROOT"`，命中即 `exit 2` 并打印进程；实测可正确拦截
（GUI 打开时复跑会明确报出 PID 25448 并中止）。
